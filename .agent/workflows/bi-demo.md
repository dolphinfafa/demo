# BI 大屏 Demo 工作流

## 文件入口

- 页面：`BI-demo/index.html`
- 样式：`BI-demo/styles.css`
- 交互：`BI-demo/app.js`
- 设计参考：`BI-demo/UI.png`

## 开发约定

1. 保持零第三方依赖；需要新增依赖时先确认。
2. 演示数据应避免出现真实客户敏感数据。
3. 新增模块时沿用 `.panel`、`.panel-title` 等基础样式，避免重复实现。
4. 目标分辨率为 1920×1080，最低支持 1180×760。

## 验证清单

- HTML、CSS、JavaScript 无语法错误。
- 页面在 1920×1080 下无模块重叠。
- 时钟、数字动画、区域筛选、城市点位、风险筛选可交互。
- 城市点位可展开项目面板，项目条目支持二次点击与状态反馈。
- 首屏核心数值均需执行递增动画，动态打开的详情指标需重新播放动画。
- 浏览器控制台无运行时异常。

## 部署方式

- 使用服务器现有 Nginx，以 `/bi-demo/` 独立路径提供静态文件。
- 公网访问地址存放于仓库根目录 `.env`，不得提交版本库。
- Nginx 配置修改前须创建备份，变更后依次执行配置检查、平滑重载和 HTTPS 验证。
